# Real-cinematic examples

These examples document the migration target for the historical `projects/PRJ01`
production: an eight-shot feature-film board with editorial shots separated from
generation segments, motivated camera-position changes, continuity snapshots, and
structured cut/J-cut/L-cut decisions.

- [PRJ01 amateur baseline](prj01-amateur-baseline.yaml) records the failure pattern: eight equal-duration generation chunks, opaque camera language, and no typed editorial/generation graph.
- [PRJ01 corrected board](prj01-corrected-board.yaml) is the review fixture for the intended eight-shot treatment.
- [three-shot executable contract fixture](../../tests/fixtures/storyboard-v2-real-cinematic.yaml) is the smaller schema/validator fixture used by automated tests.

The historical project remains untouched. These files contain only sanitized
planning metadata and no private media paths.
